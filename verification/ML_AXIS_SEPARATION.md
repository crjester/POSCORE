# VERIFY-ML-AXIS-SEPARATION
Identity: verification_id=VERIFY-ML-AXIS-SEPARATION; version=1; status=EXPERIMENTAL
Claim / gate: distinct learning questions remain independently evidenced and updated.
Applicability trigger: research with multiple model/base, tuning/treatment, analysis/calibration or other declared learning axes.
Required evidence: explicit axis identities; per-axis inputs/results/scores; update lineage; evidence cross-use rules.
Invariants: success/failure on one axis cannot substitute for absent evidence on another; shared evidence must retain axis-specific interpretation; updates target only the authorized axis.
Evaluation rule: PASS when every claimed/updated axis has independent traceable evidence; FAIL on cross-axis substitution or coupled hidden update; BLOCKED when axis lineage cannot be established.
Output: standard verification envelope.
Lifecycle effect: PASS permits per-axis conclusions/updates only.
