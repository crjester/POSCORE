# Legacy Active Work Adapter
Status: DISTRIBUTION CORE
Supported conversion requires explicit legacy: work_id, responsible legacy MODE, objective, status, next_action, authority snapshot, evidence/progress references, updated_at.
Map legacy SE/ED/ML through ALIASES to canonical role; create THREAD with preserved objective/status/next_action/evidence and historical authority snapshot, then re-resolve current authority before execution.
Legacy work missing responsible role/objective/next_action or containing conflicting current states is BLOCKED/MIGRATION_REQUIRED. Never guess.
Legacy message-only records do not become THREAD unless the message bridge validates a request and linkage.
