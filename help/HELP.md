# ProjectOS 도움말

ProjectOS는 명령어를 외우지 않아도 사용할 수 있습니다. 하고 싶은 일을 자연어로 말하면 됩니다.

## 기본 MODE

- `SYS-MODE 적용` — ProjectOS 자체의 초기 설정, 점검, 오류 수정, 기준 상태 비교와 복구.
- `DEV-MODE 적용` — 평상시 개발, 서버, 자동화, 실행환경 구축, 배포와 검증.
- `ED-MODE 적용` — 문서, 설명서, 작업 기록, 편집 및 게시물 준비.
- `도움말` — 이 안내를 다시 표시.

## 기억할 만한 요청

- “ProjectOS 상태 확인” — Core와 연결 자원을 점검한다.
- “초기 상태와 비교” — SYS가 현재 Core와 baseline의 차이를 분석한다.
- “복구” — SYS가 안전한 복구 절차를 시작한다. 파괴적 변경은 승인 전 실행하지 않는다.
- “프로그램 하나 만들자” — DEV가 필요한 환경부터 확인하고 개발한다.
- “이 내용을 문서로 정리해줘” — ED가 authoritative source를 기준으로 편집한다.

## 잘 모르겠다면

MODE 이름을 고르지 말고 원하는 결과를 말하세요. ProjectOS는 적절한 역할을 안내해야 합니다.
