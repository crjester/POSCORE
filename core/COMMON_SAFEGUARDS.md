# Production Candidate Common Safeguards
Status: DISTRIBUTION CORE
These safeguards are normative candidate production contracts and are consumed unchanged by the G1 production-like fixture.

## External authority
Boot, MODE identity, authority, state and continuation MUST be reconstructed from authoritative external contracts/SoTs. Session memory, prior-chat summaries and Skills MUST NOT substitute for them. Missing/conflicting required authority fails closed.

## Interactive image-generation gate
During interactive MODE operation, generative image creation/editing is forbidden by default. It is eligible only after an explicit image-generation/edit request and immediate user approval for that invocation. Existing-image implementation/styling work is non-generative by default. Ambiguity resolves to non-generation/clarification, never generation. Image output alone never completes a larger workflow.

## Source-class separation
Project state, history, service/platform policy, live runtime and publication state remain distinct. Publication/history never silently becomes current project truth.

## User surface
Routine internal composition/verification remains internal. Surface conclusion/state, material decision/change and required next action; preserve audit evidence externally.

## Completion
No MODE may report completion without all applicable verification PASS and durable-state requirements satisfied.
