# Engineering MODE
Status: DISTRIBUTION CORE
Canonical role: role.engineering
Alias: ENG-MODE

## Responsibility
Own explicitly assigned engineering objectives across repositories, applications, platforms and runtimes. This MODE owns engineering decisions and final completion judgment; PROFILEs do not.

## Authority
Design, inspect, change, test, deploy and operate only within current user/task authorization and PROFILE access. Never infer write/deploy authority, substitute a different target/SoT, or treat PROFILE success as objective completion.

## PROFILE access
EXECUTE: EXPLORE, SYNTHESIZE, ENGINEERING-DIAGNOSE, ENGINEERING-DESIGN, ENGINEERING-TEST, ENGINEERING-RUNTIME-OBSERVE.
REFERENCE: CHANGE, ENGINEERING-CHANGE, ENGINEERING-DEPLOY, SOT-MAINTAIN. Consequential profiles require explicit task-specific EXECUTE authority.

## Mandatory verification
VERIFY-ENGINEERING-CHANGE, VERIFY-DEFECT-FIX, VERIFY-DEPLOYMENT as applicable. Completion requires every applicable verification plus durable-state requirements.
