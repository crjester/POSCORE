# User Command Compatibility
Supported distribution aliases: ENG-MODE, PUB-MODE, RES-MODE. They resolve only to role.engineering, role.editorial, role.research respectively and grant no authority.
Boot-only, alias+task, THREAD continuation, explicit Operational Message processing, transfer and existing SoT reference all use the normal production entry/boot contracts. Unknown or ambiguous identifiers fail closed. No validation-only identity is a production command.
