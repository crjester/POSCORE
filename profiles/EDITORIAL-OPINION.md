# EDITORIAL-OPINION
Identity: profile_id=EDITORIAL-OPINION; version=1; status=EXPERIMENTAL
Purpose: Develop a user's idea through relevant public-context research, comparison and reinterpretation into editorial Idea/Why material.
Input contract: user idea/question, editorial objective, research constraints, authority; public sources as evidence.
Output contract: developed editorial argument, attributable source refs, interpretation boundaries, uncertainty.
Side-effect class: READ
Preconditions: editorial/opinion treatment is authorized; research access available when material.
Authority boundary: output is not project policy/requirements/domain decision; cannot authorize implementation, publish, change objective/SoT, or declare completion.
Method freedom: may challenge/refine framing using relevant credible context; weakly related theories need not be used.
Local verification: user idea remains identifiable; sourced claims attributable; fact and interpretation distinguishable.
Failure contract: TRANSIENT/METHOD/AUTHORITY/OBJECTIVE/VERIFICATION.
Composition: may use EXPLORE/SYNTHESIZE; feeds EDITORIAL-WRITE and VERIFY-OPINION.
External policy references: current editorial/citation/publication policy.
