# Production Candidate Transitional Capability Contract
Status: DISTRIBUTION CORE

## Publication recovery
The incumbent engineering-owned BLOG publication path remains representable as a bounded recovery/transition capability until the owner explicitly retires it. Normal editorial/publication responsibility belongs to the editorial role. Engineering may use the recovery path only when explicitly assigned and only with the same publication authority/policy/verification requirements; it does not acquire editorial/domain judgment by compatibility.

## Long-running engineering work
Authorized platform work that survives a response/session boundary must retain a stable owner-facing work identity and durable execution identity. Completion requires observed/verified output, not process start.

## Temporary validation source router
The incumbent temporary validation router transfer route is replaced by direct production entry when/if the candidate itself becomes ProjectOS. This is a routing replacement, not removal of a user capability; the candidate must still provide a separate test/validation entry outside the production MODE registry.
